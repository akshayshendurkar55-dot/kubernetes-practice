# Kubernetes Practice

A hands-on learning repository for understanding Kubernetes fundamentals and container orchestration as part of my Cloud & DevOps learning journey.

## Learning Goals

* Understand Kubernetes architecture and core concepts
* Learn how Deployments manage application replicas
* Explore Services for exposing applications
* Practice ConfigMaps for application configuration
* Write and understand Kubernetes YAML manifests
* Deploy and inspect containerized applications

## Planned Practice Areas

| Topic          | Purpose                                            |
| -------------- | -------------------------------------------------- |
| Pods           | Understand the smallest deployable Kubernetes unit |
| Deployments    | Manage application replicas and rollout updates    |
| Services       | Explore communication and application exposure     |
| ConfigMaps     | Manage non-sensitive configuration                 |
| YAML manifests | Define Kubernetes resources declaratively          |

## Tools

* Kubernetes
* `kubectl`
* Docker
* YAML

## Learning Approach

This repository will document practical exercises, Kubernetes manifests, commands, and lessons learned as I build my Cloud & DevOps skills.
